## 🎓 Customization Examples

### Change Primary Color
```css
/* In styles.css */
:root {
  --primary-color: #FF5733;  /* Your color */
  --primary-dark: #C44B35;   /* Darker shade */
}
```

### Adjust Animation Speed
```css
/* In modern-enhancements.css */
animation: fadeInUp 0.8s ease-out;  /* Slower animation */
```

### Modify Shadow Depth
```css
/* In styles.css */
--shadow-lg: 0 15px 25px rgba(0, 0, 0, 0.15);  /* Deeper shadow */
```

### Disable Parallax
```javascript
/* In interactions.js - comment out parallax code */
// window.addEventListener('scroll', () => { ... });
```
