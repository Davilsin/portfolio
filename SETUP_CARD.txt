💻 USEFUL COMMANDS (Run from backend/ folder)

  ├─ npm run dev              Start backend (development)

  └─ node DB_STATUS_REPORT    View database status

  ├─ net start MongoDB        Start MongoDB service
  ├─ net stop MongoDB         Stop MongoDB service
  └─ Get-Service -Name MongoDB | Select Status    Check status

🐛 TROUBLESHOOTING QUICK FIXES
════════════════════════════════════════════════════════════════════════════

  Problem: "Cannot connect to database"
  Fix: net start MongoDB

  Problem: "Port 3001 already in use"
  Fix: Change PORT in backend/.env to 3002

  Problem: "Admin already exists"
  Fix: This is normal! Use admin/admin123

  Problem: "Cannot find module"
  Fix: cd backend && npm install

  Problem: Backend not responding
  Fix: npm run dev (make sure you're in backend folder)

💡 PRO TIPS
════════════════════════════════════════════════════════════════════════════

  1. Use MongoDB Compass (GUI) to browse your database visually
     Download: https://www.mongodb.com/products/compass

  2. Use Postman (API tool) to test endpoints
     Download: https://www.postman.com

  3. Keep backend running in one terminal
     → npm run dev

  4. Keep frontend on separate port
     → python -m http.server 8000 (in new terminal)

  5. Backup your data regularly
     → mongodump --db portfolio --out ./backup
